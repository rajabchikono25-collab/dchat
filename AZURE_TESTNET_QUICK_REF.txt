│ MANUAL SERVER MANAGEMENT                                            │
└─────────────────────────────────────────────────────────────────────┘

  Check service status:
    sudo systemctl status dchat

  View logs (last 50 lines):
    sudo journalctl -u dchat -n 50

  Follow logs in real-time:
    sudo journalctl -u dchat -f

  Restart service:
    sudo systemctl restart dchat

  Check block production:
    sudo journalctl -u dchat | grep "Produced block"

┌─────────────────────────────────────────────────────────────────────┐
│ TROUBLESHOOTING                                                     │
└─────────────────────────────────────────────────────────────────────┘

  Service won't start:
    1. sudo systemctl status dchat
    2. sudo journalctl -u dchat -n 100
    3. sudo chmod +x /opt/dchat/dchat
    4. sudo systemctl restart dchat

  No peers connecting:
    1. sudo ufw status
    2. sudo ufw allow 9090/tcp
    3. cat /opt/dchat/config.toml | grep bootstrap_peers

  Health endpoint not responding:
    1. Wait 30 seconds (service starting)
    2. sudo netstat -tlnp | grep :80
    3. sudo systemctl restart dchat
