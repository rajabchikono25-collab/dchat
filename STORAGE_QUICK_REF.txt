┌──────────────────────────────────────────────────────────────────────────────┐
│ TROUBLESHOOTING                                                              │
└──────────────────────────────────────────────────────────────────────────────┘

CockroachDB connection timeout:
  → Check firewall (port 26257)
  → Verify SSL cert validity
  → Test DNS: nslookup absurd-auroch-17923.j77.cockroachlabs.cloud

MinIO access denied:
  → Verify credentials in testnet-config.toml
  → Check bucket policies: docker exec dchat-minio mc anonymous get dchat/dchat-media
  → Review logs: docker-compose -f docker-compose-testnet.yml logs minio

TiKV PD won't start:
  → Check ports 2379, 2380 not in use: netstat -an | findstr "2379"
  → Verify initial-cluster config in docker-compose
  → Review logs: docker-compose -f docker-compose-testnet.yml logs pd1

TiKV nodes can't join:
  → PD must be healthy first: curl http://localhost:2379/health
  → Check PD endpoints in testnet-config.toml
  → Restart in order: pd1/2/3 → wait → tikv1/2/3

Clean slate:
  .\start-minio.ps1 -Clean
  .\start-tikv.ps1 -Clean
  docker volume prune -f
